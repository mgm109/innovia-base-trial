# INNOVIA Base

情報Ⅰの授業用教材です。先生がルームを作成し、生徒はQRまたは6桁PINで参加します。

- 2進数バトル、論理回路バトル、論理回路シミュレータ、ネットワーク教材、地域マップの授業案。
- 先生用ログインとパスワード変更、授業準備画面。
- データ保存・認証・対戦の進行はSupabaseを使用します。

このリポジトリには、ビルド済みの公開用画面だけを保存しています。パスワード、秘密のAPIキー、データベースの接続文字列、設問と正解の登録SQL、参加者データ、バックアップは含めません。公開用APIキーはブラウザで使うためのものです。データへのアクセス制限はSupabase側に設定しています。

GitHub Settings → Pages → Source を GitHub Actions に設定すると、mainへの更新で画面を公開できます。

生徒は架空のニックネームを使ってください。先生のログイン情報は生徒に共有しないでください。

公開用画面は2026年10月1日の確認用版です。既存のSites公開版は別のまま保持しています。

先生用画面の「教材の並び順を設定」から別ページで順番を変えると、先生・生徒の教材一覧に同じ順番で反映されます。

「プロトタイプで教材を試す・追加する」では、新しいアプリの教材名・説明・リンク先を試作として登録できます。カードから試し、「試して内容を確認しました」にチェックを入れて「生徒用に追加」を押すと生徒の教材一覧に追加されます。登録内容の変更も、確認して反映するまで生徒用には出ません。アプリの詳しい制作や登録はCodexに頼めます。４択練習問題の作成も任意で利用できます。

地域マップの専用ページは現在、既存の授業案を表示します。

先生用画面では、すべての教材の「公開する」「非公開にする」を切り替えられます。非公開にすると生徒の教材一覧から隠れ、先生用には残ります。並び順も保たれます。静的アプリの直リンクへのアクセス禁止とは異なる設定です。

「フローチャートをつくろう」は、順次・分岐・繰り返しの身近な例から、自分で手順を組み立てる教材です。図の「＋」で場所を選び、記号を追加して文章を入力します。PDFでパソコンに保存でき、「編集用に保存」したファイルを読み込むと続きを作れます。作業内容はブラウザー内に保存し、サーバーへは送信しません。

新しいフローチャートは先生のプロトタイプ一覧に試作として登録しています。内容を試して確認した後、「生徒用に追加」で生徒の教材一覧に追加できます。
